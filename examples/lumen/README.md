# Lumen example

A complete shotforge project for a made-up planner app, in English and Vietnamese.

```bash
cd examples/lumen
npx shotforge render        # or: npm run dev -- render -c examples/lumen/shotforge.json from the repo root
npx shotforge gallery       # the same screens in every theme
```

What it shows:

| Slide | Layout     | Technique                                                          |
| ----- | ---------- | ------------------------------------------------------------------ |
| 1     | `hero`     | Big device, highlighted keyword, a decorative 3D asset             |
| 2     | `span`     | An oversized device that continues into slide 3                    |
| 3     | `object`   | No device, a 3D object with a call-to-action pill                  |
| 4     | `callouts` | Cards lifted out of the screen, with a kicker label                |
| 5     | `tilted`   | Tilted device for rhythm                                           |
| 6     | `hero`     | Dark screenshot on a light theme, decoration bleeding off the edge |

The screenshots in `shots/` are mockups of a fictional app. Photos inside them come from [Lorem Picsum](https://picsum.photos).
