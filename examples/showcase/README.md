# Theme showcase

Every theme rendered with a sample app that fits it: a bank for `dark-premium`, a gym app for `neon-sport`, a language app for `caption-blocks`, and so on. This is the source of the theme grid in the main README.

```bash
npm run showcase   # renders each theme and writes docs/images/themes.jpg
```

- `showcase.json` lists one app per theme: its brand colors and three slides.
- `shots/` holds the sample screens. They are mockups of fictional apps; photos inside them come from [Lorem Picsum](https://picsum.photos).

Adding a theme? Add an entry here too, with screens from an app category the theme is made for.
